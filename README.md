## 🕹 Управление

| Действие | ПК (Клавиатура) | Телефон / Планшет |
|---|---|---|
| **Движение** | `A` / `D` или `Стрелки влево/вправо` | Виртуальная крестовина `◀` / `▶` |
| **Прыжок** | `Пробел` или `W` / `Стрелка вверх` | Кнопка `🦘 ПРЫЖОК` |
| **Двойной прыжок** | Повторное нажатие прыжка в воздухе | Повторное нажатие `🦘` в воздухе |
| **Выстрел искрой** | `F` или `J` / `Shift` | Кнопка `⚡ ВЫСТРЕЛ` |
| **Переключение музыки**| Клавиши `1`, `2`, `3` | Кнопка `🎵 Трек` в шапке |
| **Вкл/Выкл звук** | `M` | Кнопка `🔊` / `🔇` |
| **Рестарт уровня** | `R` | Кнопка `🔄 R` |

## 🌟 Особенности игры

* **6 уникальных и сбалансированных уровней** — от Зачарованного леса до Сердца Тьмы.
* **Механика Марио:** врагов (слизней и летучих мышей) можно растаптывать прыжком сверху!
* **Боевая система:** робо-кот стреляет энергетическими искрами на расстоянии.
* **Двойной прыжок:** свободное преодоление любых пропастей и шипов.
* **3 фоновых саундтрека:** возможность переключения прямо во время игры.
* **Пиксельная графика и HUD:** честные хитбоксы, пиксельные сердечки, парящие кристаллы и анимированный кот.
* **Система рангов:** получите ранг **S+ (Легендарный Кот)** при наборе от 450 очков!

## 💻 Локальный запуск на Python (Pygame Zero)

Если вы хотите запустить проект локально через Python:

1. Убедитесь, что установлен Python 3.8+:
```bash
python --version
```

2. Установите Pygame Zero:
```bash
pip install pgzero
```

3. Запустите игру:
```bash
python main.py
# или
pgzrun main.py
```
